КАК ДОБАВИТЬ НОВУЮ КАРТИНУ

1. Поместите фотографию картины в эту папку.
2. Назовите файл латиницей, например: painting-04-nazvanie.jpg
3. Откройте app/main.py и добавьте новый блок в список PROJECTS по примеру
   трёх существующих картин.
4. В поле image укажите путь:
   /static/images/paintings/painting-04-nazvanie.jpg

Рекомендуемый формат: JPG, ширина от 1600 px, размер файла до 2–3 МБ.
